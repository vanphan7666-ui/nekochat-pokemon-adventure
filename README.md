# 네코챗 포켓몬 모험 JSX (베타)

네코챗에서 포켓몬을 키우며 서사를 진행하기 위한 1:1 배틀·상태창 JSX입니다. 화면은 5세대풍 픽셀 디자인이며 원작 게임이나 Pokémon Showdown의 완전한 전투 엔진은 아닙니다.

## 설치

1. `PokemonBattle.jsx`를 네코챗의 별도 JSX에 붙여넣고 `PokemonBattle`로 등록합니다.
2. `PokemonStatusBW.jsx`를 다른 JSX에 붙여넣고 `PokemonStatusBW`로 등록합니다.
3. `PokemonAdventure.prompt.txt`를 모험용 프롬프트에 추가합니다. 이전에 같은 역할의 운영 규칙이 있다면 교체합니다.
4. 첫 포켓몬은 실제로 받은 장면에서 설정합니다. 예: `<PokemonStatusBW sync={{p:[["charmander",5,"starter-0"]],a:"starter-0"}} />`

일상에는 상태창만, 야생·트레이너 조우에는 배틀과 상태창을 각각 출력합니다. 두 JSX에는 동일한 최신 `sync`를 전달합니다. 버튼 조작 뒤 생성된 `[POKEMON_SYNC]` 전체를 다음 응답에 계승해야 포켓몬·가방·돈·마스터 학습장치 설정이 유지됩니다.

## 기능과 한계

- 포획, 이로치 조우·보관, 경험치·레벨업, 기술 습득·교체, 진화, 메가진화, 특성·성격·노력치, PC, 가방·상점 등을 지원합니다.
- 야생 이로치는 기본 1/4096 확률로 등장합니다. 확정 조우에는 `encounter={{species:"구구",level:3,wild:true,shiny:true}}`를 사용합니다. NPC 파티는 해당 포켓몬 항목에 `shiny:true`를 넣습니다.
- 배틀 배경은 `encounter.place`의 장소에 맞춰 선택됩니다. 예: `place:"도시"`. 원하는 배경을 직접 고르려면 `encounter.background:"cave"`처럼 지정합니다. 숲·초원·도시·경기장·동굴·설원·사막·해변 등 17가지 배경을 지원합니다.
- 기술과 배틀 규칙은 스토리용 1:1 배틀에 맞춰져 있습니다. Z기술과 다이맥스·거다이맥스 기술은 포함되지 않으며 일부 원작 예외 규칙은 단순화되었습니다. `MOVE_SUPPORT.md`를 참고하세요.
- 도트·트레이너·배경·효과 이미지는 Pokémon Showdown과 일부 PokéAPI URL에서 불러옵니다. 이미지 파일은 이 저장소에 포함하지 않습니다. 외부 주소가 바뀌면 표시되지 않을 수 있습니다.
- 네코챗 환경용 JSX이므로 일반 React 프로젝트에 바로 설치하는 형태는 아닙니다.

## 업데이트와 저장 데이터

상태창의 **풀숲 가챠**는 버튼을 누를 때 ₽10,000을 차감하고 3마리 중 1마리를 선택합니다. 메가진화 폼을 제외한 1,283종 포켓몬·폼을 같은 확률로 추첨하며 한 번의 후보에는 동일한 폼이 중복되지 않습니다. 전설·환상·리전폼은 포함되며 메가자리·메가니움도 일반 포켓몬으로 등장합니다. 실루엣에서 왼쪽 → 가운데 → 오른쪽 순서로 도트와 이름이 공개된 뒤 선택할 수 있습니다. 레벨은 PC를 제외한 현재 파티 평균을 반올림합니다(빈 파티 Lv.5). 파티가 6마리면 선택한 포켓몬은 PC에 보관됩니다. 결제·연출 중에는 후보와 차감된 돈을 내부에 저장하고, 포켓몬 선택 완료 때만 최신 `POKEMON_SYNC` 메시지를 전송합니다. 선택 대기 기록은 가방 저장값과 선택 필드 `sync.q`로 복원하므로 **최신 운영 프롬프트와 두 JSX를 함께 갱신**해 주세요. 이미 낸 비용은 화면을 나가도 반환되지 않으며, 같은 후보를 다시 열어 선택할 수 있습니다. 이전 버전의 선택 대기 메가폼은 추가 결제 없이 원래 모습으로 바뀝니다.

상점의 **폼체인지** 분류에서 녹슨검·녹슨방패, 전용 구슬, 플레이트·메모리·카세트·가면 등을 구입해 지닌물건으로 줄 수 있습니다. 그라시데아꽃·비추는거울·로토무카탈로그 등은 가방에서 대상과 모습을 선택하는 재사용 도구입니다. 모험용 편의를 위해 시간·합체 재료 조건은 요구하지 않습니다. 퀵볼은 첫 턴 5배·이후 1배, 타이마볼은 첫 턴 1배에서 완료된 턴마다 0.3배씩 올라 11번째 턴부터 최대 4배의 포획 보정을 적용합니다.

새 버전 적용 전 현재 대화의 최신 `[POKEMON_SYNC]` JSON을 따로 보관하세요. 업데이트 내역에 저장 형식 변경이 있다면 기존 기록과의 호환 여부를 확인하세요.
